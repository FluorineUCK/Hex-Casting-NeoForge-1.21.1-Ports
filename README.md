## Repository model

- `origin`: the `FluorineUCK` port repository.
- `upstream`: the original project repository.
- Publication/default branch: `pre39`.
- `phlib`, `iotaworks`, and `hexic` remain together in `Hex-Addons-NeoForge-1.21.1`.
- **Heartxxy** is the repository/project name; **Pregxxy** is the in-game name and **`pregxxy`** is its mod ID.
- **HexxySable** retains its new name and icon; historical HexxySkies references identify its original upstream only.
- Exact source, upstream base, and current port commit mapping: [repositories.json](repositories.json).

## Upstream documentation and licenses

Every port README links its original project and exact source commit. `UPSTREAM.md` indexes the original README, changelogs, credits, licenses and `upstream-docs/` archive. Inherited loader/version instructions describe the original project; use each port's `PORTING.md` for the current port baseline.

Original license and copyright notices are retained rather than replaced by a collection-wide license. HexTweaks' recorded upstream tree does not contain a standalone project-root license; its third-party asset licenses are scoped to those assets. See its **Docs & licenses** entry for the recorded files.

## Excluded port

HexOverpowered is intentionally not published because its original author does not permit submission.
