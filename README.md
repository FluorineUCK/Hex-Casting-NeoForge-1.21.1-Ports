# Hex Casting NeoForge 1.21.1 Ports — pre53

20 个源码仓库，22 个模组 ID。Minecraft **1.21.1** / NeoForge **21.1.234** / Java **21** / Hex Casting **0.12.0-devel-pre-53**。

这是实验性移植版本。原 pre39 分支保留；本次发布不更改仓库可见性或默认分支。各原作者署名、许可证与历史文档保留于对应源码仓库。

## 下载与安装

各仓库 Release 提供已验收的普通运行 JAR；文件名中的旧 `probe` / `SNAPSHOT` 后缀保留，以维持实测制品哈希，不表示附带独立测试探针。集合 ZIP 仅包含下列 22 个附属模组，不包括 Hex Casting、NeoForge 或第三方前置依赖。前置的实际测试版本及哈希见 [DEPENDENCIES.md](DEPENDENCIES.md)，每个模组的声明依赖见其 PORTING.md。不要混用 pre39 制品。
